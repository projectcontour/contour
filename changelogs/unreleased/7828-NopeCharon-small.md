The handling of `ETag` headers on compressed responses can now be configured via `compression.etag` in the configuration file or `spec.envoy.listener.compression.etag` in the `ContourConfiguration` CRD. `remove` (default) keeps the existing behavior of removing strong `ETag` values from compressed responses, `weaken` keeps them as weak `ETag` values by prepending `W/`, and `skip` disables compression of responses that carry an `ETag` header.
